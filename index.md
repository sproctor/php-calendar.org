PHP-Calendar is an open source web calendar. It is intended to provide a simple
solution with an intuitive interface. It is targeted to groups and individuals
with the need to track events with an emphasis on group collaboration. In that
same collaborative spirit, the source for PHP-Calendar is available under the
open source [Apache 2.0 license](https://www.apache.org/licenses/LICENSE-2.0.html) to facilitate collaborative development.

### Download
The latest release is **[PHP-Calendar 2.0.14](https://github.com/sproctor/php-calendar/releases/latest)**,
a security release that everyone running 2.0 should upgrade to. It requires PHP 8.1 or later and MySQL or
MariaDB. See the [installation guide](https://github.com/sproctor/php-calendar/wiki/Installation-Guide) to
get started. Version 3.0 is in development.

### Demos
* [Release](https://demo.php-calendar.org/) - Demo of the latest stable version (2.0)
* [Development](https://dev.php-calendar.org/) - Demo of the current development line. It may be broken, but it should show off some of the newest enhancements.

Log in as **demo** with the password **demo** to add and edit events. The demos are reset every night.
